# Third-party notices

Перечень точных версий прямых зависимостей — в `package.json`, всех транзитивных — в `package-lock.json`. Полные доступные тексты лицензий установленных npm-пакетов сохранены в `THIRD_PARTY_LICENSES.txt`.

## Runtime

- React, React DOM — MIT. Компоненты и DOM-рендеринг.
- React Router DOM — MIT. Маршрутизация и URL-состояние.
- TanStack React Query — MIT. Запросы, кеширование и мутации.
- Lucide React — ISC. Локальные SVG-иконки.
- Mock Service Worker — MIT. Демонстрационный HTTP API в браузере и тестах. `public/mockServiceWorker.js` — сгенерированный worker из MSW, включая его собственное уведомление об авторских правах.

## Development

- TypeScript — Apache-2.0.
- Vite, плагин React для Vite, Vitest — MIT.
- Testing Library React, user-event, jest-dom — MIT.
- jsdom — MIT.
- Типы React и React DOM из DefinitelyTyped — MIT.

Node.js и nginx используются как среда исполнения сборки/контейнера; лицензии компонентов базовых образов распространяются вместе с этими образами. Изображения и внешние шрифты отсутствуют. Иллюстративная SVG-диаграмма написана специально для прототипа. Название и стилистика Альфа-Банка используются в контексте запрошенного хакатонного прототипа; проект не выдаётся за официальный продукт.

## Данные и интеграции

Три компании, все семь событий, персонализированные выводы, признаки, демонстрационные аналитические заметки банка и сообщения созданы синтетически для этого проекта. Реальные клиентские CSV, реальные публикации банка и чужие наборы данных не включены. Представленный PDF использован как контекст продуктовой задачи, не распространяется в проекте.

Нет вызовов LLM, платных сервисов, банковских систем, реальных новостных API и сторонней телеметрии. Модель AI, парсинг, рейтинг событий, проверка источников и этапы анализа имитируются детерминированными обработчиками MSW. После отключения MSW приложение работает только с заданным HTTP API, без резервной подстановки синтетических данных.
