| Проверка | Результат |
| --- | --- |
| `npm run typecheck` | Успешно |
| `npm test` | 9 тестов, все прошли |
| `npm run build` | Успешная production-сборка |
| Сборка с `VITE_ENABLE_MOCKS=false` | Успешно; отдельный промежуточный каталог |
| Установка зависимостей | npm сообщил 0 известных уязвимостей на момент установки |
| `npm run dev` | Проверен запуск и загрузка персональной ленты в браузере |
| `npm run preview` | Проверены главная/лента/разбор, источники, Escape, чат и завершение обновления |
| Адаптивность | Проверка во фреймах шириной 390, 768 и 1440 px; горизонтального переполнения контента не обнаружено |
| Docker | Конфигурация подготовлена; Docker Engine отсутствовал, запуск образа не проверен |

Визуальная проверка 390 px: лента и подробный разбор. При 768 px: подробный разбор. При 1440 px: структура ленты и отсутствие переполнения. Фактическая ширина контента меньше ширины фрейма на полосу прокрутки.

Тесты используют реальные HTTP-запросы API-слоя, перехваченные MSW, и рендерят компоненты через Testing Library. Проверяют:

1. Сброс фильтров в URL и возврат полной ленты.
2. Серверные этапы обновления и частичное завершение.
3. Переход с главной и смену компании без старого аналитического контекста.
4. Открытие источника непосредственно из утверждения.
5. Ошибку/повтор вопроса и изоляцию историй по компании, событию и роли.
6. Повтор запроса после ошибки API ленты.
7. Фильтрацию на API и ранжирование по роли.
8. Различение 403, 404 и отсутствующей позиции банка.
9. Неизвестный продукт и честное ограничение неизвестного вопроса.

Интеграция с настоящим сервером, банковскими системами и LLM не проверялась: эти компоненты отсутствуют в согласованном объёме. Проверка адаптивности во фрейме не заменяет тестирование на физических мобильных устройствах. Временная страница проверки не включена в поставку.
